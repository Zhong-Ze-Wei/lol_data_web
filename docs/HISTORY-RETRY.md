# 待发布系列的阶段重试

待发布系列需要重新读取所属阶段赛程，才能确认战报是否已发布；不能直接猜单局 ID 或仅凭旧错误文本把它改为已完成。系列到期不会绕过父阶段的重试次数和失败退避：失败次数已达到本批 `max_attempts` 的阶段仍保留 `failed`、次数、错误和重试时间；尚在退避中的阶段等待自己的重试时间。仅真实请求成功后，既有成功流程才清除失败状态。

覆盖报告的 `has_runnable_work` 沿用实际可执行的资格。可到期刷新的父阶段与直接排队的阶段合并计数，同一阶段只计一次；被耗尽或退避父阶段阻塞的待发布系列不计为当前可运行任务。它们仍保留在待发布数量中，耗尽失败也继续计入失败和耗尽数量。已排队或可重试的系列及已知单局任务仍可独立采集，不因阶段失败而一概阻止。

`next_retry_at` 表示真实可执行工作的下一次等待时间。失败父阶段自己的重试时间保留；依赖该阶段的系列不能用更早的时间提前唤醒空批次。耗尽父阶段下的待发布系列不提供自动恢复时间，也不自动重置失败预算；有其他合法任务时仍可继续执行。

后台没有当前可运行任务、没有合法下一次重试且仍有失败缺口时，既有执行器以失败状态退出，保留报告供核查。`snapshot_completed` 表示本轮快照已经审计，不代表所有来源战报已经完整；待发布、源缺项和未关联缺口仍由 `complete_available=false` 明确保留。

验证使用本地响应夹具和隔离 SQLite，覆盖阶段 404 达到预算后的连续批次、19 个耗尽阶段不被隐藏、父阶段退避、合法复采恢复、同阶段任务去重、系列及单局独立采集，以及不同重试预算。不请求真实网站、调用 AI、读取生产数据或修改已有原始档案。
