# ADR 0002：历史顺序与采集吞吐

- 日期：2026-10-04
- 状态：近期优先已采用；0.2 秒间隔已通过一次有界实际验收

## 背景

用户查询 Faker 近年比赛时发现缺失。调整前的实际只读/API核验有 1211 局 Faker 出场，其中 2022 年 144 局、2023 年 134 局、2024 年 80 局，最新为 2024-05-18 MSI。2024 LCK 夏季及后续 2025、2026 年相关目录仍有 queued、尚未展开阶段的情况。缺口来自采集尚未轮到，不能归为已采数据被页面隐藏。

原历史队列按赛事开始日期从旧到新。即使每天和后台都运行，近期目录仍需等待早期赛事，不能及时支持当前选手分析。

另一次实际性能核验的最近 10 批均为 400 次请求，平均约 409.87 秒。1 秒请求起始间隔下，仅 399 个相邻请求间隔的理论下界就是 399 秒，占该平均批次时长的约 97.35%。这是下界与总时长的比例，不是测得实际 sleep 占用了 97.35%，也不能把剩余时间直接归给网络、SQL 或入库。

该基线在05:35:18.942871 UTC以只读事务查询run157–166，并绑定10份已有报告的实际SHA；总4000请求、4098.699秒。报告中的2369个去重accepted ID不是逐批新增比赛数，不能用较早冻结库的分类代替每批before/after集合差。证据 `artifacts/history-performance-baseline-20261004.json` 的SHA为 `c51f817742f55c7fffbe4b7dc99b5d7925542c600563450b1f0eb9314d0d7730`，在本机ignored artifacts中。

## 决策

历史队列优先已知开始日期较新的赛事，未知日期最后。所选赛事已有单局、系列和阶段优先处理，再进入下一赛事；系列与单局也按已知赛程日期从新到旧。没有可运行赛事目录时，未关联单局使用相同的日期顺序，不根据 resultID 猜日期。

继续覆盖全部历史，不清除旧队列、已成功游标、失败次数、退避期限或终态。没有可运行工作时结束本批，真实等待和失败仍公开。已采完整数据不因为改顺序而全量重采。

采用0.2秒间隔的串行、有界补采，允许显式降速，不新增并发池。先通过现有参数做一次 canary：`--min-interval 0.2 --max-requests 200 --max-seconds 120`。每次尝试仍计入预算，保持来源归档、身份验证和失败退避；记录实际请求数、时长、429/失败、入库和缺项。参数间隔降到原来的五分之一不代表总耗时已经加速五倍。

持久后台控制器公开间隔参数并以0.2秒为默认值的实施正在独立功能分支验证，可显式覆盖；这项实现尚未由本记录部署。当前驻留控制器未重启，仍使用其既有参数；显式快速批次和控制器下次正常启动的默认值分别记录，不能把试跑参数称为当前驻留进程已经采用0.2秒间隔。

## 取舍

近期优先能更早补上当前用户关心的数据，但旧历史完成时间可能延后；旧工作仍在队列内。单纯改顺序不能补出上游未发布或不可访问的战报。更短间隔可能提高吞吐，也可能遇到来源限流；有界串行试验可使用现有持久状态继续或恢复参数，无需重置失败状态。

HTTP404、身份矛盾和 `source_incomplete` 继续保留真实含义，不为提速把它们改成成功或全部完成。页面只显示已采事实，实际近期补齐程度由采集结果决定。

## 验证与关联

近期优先修改已通过 9 项定点及功能分支完整构建/测试，覆盖新日期先选、未知最后、预算续批不重采成功前缀、同赛事未完成工作优先、原失败上限和退避不变。调度测试使用临时数据库和模拟来源，不是近期比赛已经实际补齐的证明。

2026-10-04 05:48:50–05:50:06 UTC 的真实 canary 在同一采集锁内串行运行：200 次实际请求用时 76.125 秒，约 2.627 次/秒；200 个响应均 HTTP200，无429、5xx或未取得响应的预算请求。相较此前约 0.976 次/秒，本次吞吐约为 2.7 倍；批次处理内容和来源不同，不承诺全量持续保持这个倍率。报告中的 41.326794 秒是响应头计时累计，不是完整网络耗时。

该次管道以正常预算退出码4结束；验收包装器检查通过后返回0，不把预算退出误写为全部完成。同锁前后明确 resultID 集合证明新增133局、移除0局：123局 `imported`、10局 `source_incomplete`。新增数由集合差取得，而不是把所有 `imported` 默认当新局；133个本次 outcome ID 均属于新集合。

随后13:51香港时间的实际 API 显示 Faker 1307局，最新为2026-09-12、战队T1。由1211到1307的推进包含近期优先上线后原后台400请求批次与本次200请求canary的共同作用，不能归为canary单独增加96局，也不等于Faker历史已经全齐。
