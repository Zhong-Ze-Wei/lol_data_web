# ADR 0005：目录游戏范围的来源例外

- 日期：2026-10-04
- 状态：已采用；当前落实范围为冻结的 pub0 差集补探计划

## 问题与证据

ScoreGG 目录归档的顶层 `gameID='1'`，包含 388 个唯一赛事 ID，但 388 行均没有独立 `gameID`。顶层字段可以选择发现入口，不能证明每个赛事实际都属于 LOL。[ADR 0001](0001-lol-source-and-coverage.md) 已按新证据纠正这一边界，原核验报告和原件校验值保留。

目录项 431 的实际名称是「2022 卡塔尔世界杯」。已归档的两个阶段包含 64 条国家队足球赛程，BO 为 27403–27466；逐行审计已校验全部 64 条的赛事、阶段、显式 BO、原行与原件 SHA 绑定。例如 BO 27403 为卡塔尔对厄瓜多尔 0:2，BO 27404 为英格兰对伊朗 6:2。来源范围判断采用实际赛程内容及逐行归档绑定，未为这些没有游戏字段的行补造 `gameID`。

## 决策

1. 保留永久目录项 431、原始阶段与历史审计，目录分母仍为 388。已证实的范围例外单独记录，不通过删除目录项改变发现历史。
2. 在本次冻结 pub0 差集计划中阻断 431 的全部 64 条足球系列；新 v2 入口只对余下 1191 条候选补探真实 BO 的 resultlist。差集 1255 = 可补探候选 1191 + 来源范围阻断 64，原 629 条已探测 ID 不在重复请求范围内。
3. 1191 条候选仍继承目录页面的发现范围，未获得逐项游戏认证。探到真实 resultID 后，业务入库仍须按完整详情或 metadata 的明确游戏标记和身份绑定核验；差集补探本身不写业务数据库、不改 `is_publist`、不猜 resultID。
4. 不按「世界杯」或 EWC 名称批量删除。已检查的 EWC 项 991、973、962、865、751 分别有 GEN/KC、KRX/DNS、EDG/UP、FLY/C9、BLG/T1 等 LOL 对阵证据，继续保留。其余未逐项检查的赛事不因这组样本而自动得到认证。

## 实施范围与取舍

当前实施仅为本次冻结差集计划及其 v2 补探入口；常驻 `history`/`daily` 的足球目录范围策略没有因本 ADR 自动改变。本文未删除主库记录、重置失败计数、修改原件或重新探测原 629 条，也不宣称 1191 条补探已经全部执行完成。未来若扩展为常驻策略，应沿实际目录与赛程绑定记录例外，并单独验证部署行为。

上述数字来自 2026-10-04 07:26:43–07:26:55 UTC 取得的同一一致性快照及其后续来源范围审计；原采集器当时继续运行。快照仍有 29 个失败阶段、4 个待发布阶段。388/388 目录展开、单次补探结束和来源范围排除，均不能替代完整单局清单与可获取历史完成条件。

来源绑定通过与游戏范围通过是两项检查。计划保留的原快照统计曾将 1255 条列为绑定就绪；新的 `execution_scope_notes` 才明确 1191 条可补探、64 条范围排除。读取计划时应使用冻结的执行范围，不把旧绑定统计当成全部允许执行或已认证 LOL 的数量。

保留完整目录便于追溯来源错误，也避免把电竞世界杯等合法 LOL 赛事误排除。代价是覆盖报告需继续显示已知例外和未解决阶段，不能把剩余 387 个目录项写成已逐条认证。
