# ADR 0001：LOL 来源与覆盖范围

- 日期：2026-10-04
- 状态：已采用；覆盖数字仅代表核验时点

## 背景与证据

用户要求补齐全部可获取的 LOL 历史比赛。官网当前返回 388 个唯一赛事目录项，它们跨 2011–2026 年，并有 1 项开始日期未知。历届、春夏季、赛段、区域联赛和杯赛分别计数；388 不等于 388 个顶级联赛，也不等于 388 项已经采完。

本次只读核验的 `data/raw/history/catalog.json` 顶层 `gameID='1'`，实际字节 SHA 为 `5d2af306ef9459dff48077e54f4e70e3abdcbe0423f8072a159ed3061ea46eab`。名称包含 LCK 第三赛段、LCS 夏季赛、CBLOL 第二赛段、KeSPA 杯和 EWC LOL 等。388 行本身均没有 `gameID` 字段；这个已确认的顶层字段只能说明页面标记，不能逐项认证目录中的赛事。2026-10-04 的后续来源复核已发现目录项 431 实际包含足球赛程，补充证据与落实范围见下文及 [ADR 0005](0005-catalog-game-scope-exception.md)。

有限读取的 7 份已绑定赛事阶段定义原件均匹配数据库 SHA；这些原件是 round 列表，没有顶层游戏标记。另 2 份已有官网赛程页归档的顶层 `gameID` 均为 1。赛事名称未命中此次常见非 LOL 游戏关键词筛查，关键词结果只辅助检查，不能证明每项内容的游戏归属。

## 决策

保留官网顶层标记 LOL 的完整目录与原始证据，不按联赛知名度删除小赛区或杯赛。以目录、阶段、BO 系列、单局四层分别展示进度，并保留未知日期、失败、待发布和来源缺项。发现范围与可入库的 LOL 比赛范围分别判断；本次已证实的足球系列从冻结差集补探计划排除，永久目录仍保留。

来源核验沿现有入口进行：

- `parse_tournament_page` 要求页面明确 `gameID=1`；目录由这个页面展开。`_discover_tournament` 使用其中的赛事 ID 读取阶段定义并验证结构，不再单独证明每个阶段所属游戏。
- 完整详情 `normalize_result` 先验证请求的单局 ID；响应含 `resultID` 时必须是合法正整数且与请求一致，缺少此键仍保留原入口合同。随后只接受明确正整数 `data.gameID`：1 为 LOL，其它明确正整数才能证明非 LOL。缺失、空值、布尔、浮点或其它无效游戏标记均记录普通失败，保留旧比赛及关联出场。只有目标身份未矛盾且游戏明确非 LOL，才清理 `legacy`、未核验的派生记录；已核验记录仍保留。不靠旧 CSV、目录名称或 ID 猜游戏。
- 官网 metadata 必须自行明确 `gameID=1`，并与真实归档赛程交叉 BO、赛事、双方 ID、时间及原行 SHA。缺少游戏标记不能通过补一个 1 进入 LOL 数据。
- 完整详情实际 404 时，独立 metadata 可以保存其真实基础统计；缺少角色、精确秒数和个人指标仍为 NULL，标记 `source_incomplete`。来源身份核验通过不等于完整指标已记录。

## 取舍与边界

保留全部目录符合“全部可获取”的目标，代价是目录项多、历史上游入口有缺失，近期覆盖需要另外调整队列顺序。目录展开成功只说明阶段定义读到；BO 清单和单局详情仍需分别采集。HTTP200 空清单、404、失败耗尽或基础统计缺项均不能作为全部完成的证明。

顶层 LOL 标记提供候选发现入口，但不能证明每个赛事或代替每条战报的身份核验。阶段接口本身缺少独立游戏标记；历史来源也曾出现重复 BO 或双方身份冲突。保留失败和原始证据，拒绝显式矛盾，不用名称猜别名、赛事或日期。此记录不宣称官网没有错误，也未独立核验全部 388 项的所有阶段和详情。

2026-10-04 05:51:59 UTC 的另一次窄只读核验，发现4个单局任务明确因 `gameID=2，不是 LOL` 被跳过；这些 resultID 当前关联的 Match 为0，未保留为可展示比赛。这证明这4条确实排除了非LOL来源，不认证全部旧CSV数据。页面默认没有限定 `verified` 时，目录的LOL标记不能反向认证仍未核验的旧记录；上述4条不显示是源码/SQL结论，未另做网页实调。

## 验证与关联

### 后续范围纠正：目录项 431

2026-10-04 08:08:58 UTC 的来源范围复核确认，目录项 431「2022 卡塔尔世界杯」的实际归档赛程包括卡塔尔对厄瓜多尔 0:2、英格兰对伊朗 6:2 等国家队足球比赛。08:15:12 UTC 的补充审计逐一校验了两份阶段原件中的全部 64 条系列行及其 BO、阶段、赛事绑定和原行 SHA。该证据纠正了此前由页面标记继承目录游戏范围的无条件表述；原目录 SHA、早期只读报告及其当时观察仍保留。

冻结差集的 1255 条系列中，1191 条保留为可补探候选，431 的 64 条以来源范围例外阻断；原 629 条已探测系列仍排除，不重复请求。1191 条候选未获得逐项 LOL 认证，后续战报入库继续要求明确游戏标记。该排除目前仅落实在新的 v2 差集补探计划，未修改常驻采集器的足球范围策略，也未删除永久目录或业务数据。该快照仍有 29 个失败阶段和 4 个待发布阶段，目录展开 388/388 不代表全部比赛完整。

EWC 目录项 991、973、962、865、751 的已检查赛程有 GEN/KC、KRX/DNS、EDG/UP、FLY/C9、BLG/T1 等真实 LOL 对阵，仍保留；不能按「世界杯」或 EWC 名称统一排除，也不能由这一组检查反向认证其他 387 项。完整证据、校验值和实施边界记录在 [ADR 0005](0005-catalog-game-scope-exception.md)。
