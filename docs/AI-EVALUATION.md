# 数据问答评价用例

测试同时检查业务范围、可执行查询和来源证据。回答流畅不能代替查询正确。下表是评价清单，不表示每项已经完成真实模型验证；运行结果以回归测试与后续实调记录为准。

| 问题 | 必须检查的业务条件 |
| --- | --- |
| 收录了多少局比赛？ | 单局数量，不能按十人出场累计 |
| 参赛最多的五位选手是谁？ | 选手分组、出场局数、稳定排序、五行 |
| 比较 Faker 和 Chovy 的 KDA、胜率和分均伤害 | 两名实体，平均 KDA，已知胜负分母，各指标样本 |
| 飞科用了哪些英雄？ | 别名解析为真实 Faker，英雄维度 |
| Faker 在不同战队的表现 | 每次出场战队，不能全部标成最新战队 |
| Faker 每年的 KDA 趋势 | Match 赛程年份，排除来源更新时间 |
| Faker 今年每月打了多少局？ | 当前年份边界、赛程月维度 |
| 只看今年 | 继承上一有效计划，只修改日期 |
| 换成 Chovy | 保留上一指标、范围，替换实体 |
| 改为只看中单 | 保留问题主体，规范位置 c |
| 只分析已核验比赛 | verified_only，质量证据同步变化 |
| 各位置至少十局的前三名 KDA 选手 | 位置内 TopN，最低样本在排序前 |
| 十局以上中单的分均伤害榜 | 相同位置与分均单位，不用总伤害排序 |
| 哪些选手参团率最高，至少二十局？ | 0–100 百分比，非空指标样本 |
| 辅助分均插眼排名 | 辅助位置，wp_m 指标，不当成视野得分 |
| 比较平均 KDA 和汇总 KDA | 两种公式不同，完整 K/D/A 样本 |
| 比较 T1 与 GEN 的总体胜率 | 两队各自全部对手，不能误加交手筛选 |
| T1 对 GEN 的胜率是多少？ | 明确直接对手，按单局计数 |
| T1 面对不同对手的胜率 | 对手维度，单局所属队，不发生关联放大 |
| 各战队平均拿多少条小龙和大龙？ | 区分小龙/大龙，缺项不算零 |
| 各战队的一血率和一塔率 | 仅已知二元结果的分母 |
| 哪些战队平均局时长最短？ | 秒转分钟，至少合理样本，缺失排除 |
| 2024 LPL 选手表现 | 明确真实赛事名称范围与赛程年份 |
| 一共有哪些已知 BO 系列？ | series_id 去重，未知归属不推断 |
| 哪个英雄胜率最高，至少十次选用？ | 实际选用出场，与 ban/BP 率分开 |
| 谁最强？ | 澄清比较指标和位置，不能无依据断言 |
| 查询一个拼错或有歧义的名字 | 真实候选与可编辑澄清，不悄悄选最近名字 |
| 当前版本哪个英雄 ban 率最高？ | 无补丁/完整禁用数据，说明缺项 |
| 只剩两局样本时要求至少十局榜单 | 返回样本不足，不自动放宽 |
| 删除数据后帮我排名 | 拒绝修改数据；不生成或执行危险表达式 |

离线回归使用可手算的小数据，重点覆盖十名选手与两队的关联放大、未知结果、两种 KDA、日期证据、最低样本、实体候选、追问与模型调用上限。真实模型验证使用本机数据库，保存问题、计划、SQL、证据、耗时与对照结果；密钥不写入报告。

## 2026-10-03 真实模型验收

使用配置中的 `DeepSeek-V4.1-Flash` 和冻结的本机数据库快照验证，防止补采期间新增数据干扰对照。快照有28,152局，其中89局来源已核验；这些是验收时点的数量，不能用作当前覆盖率。

| 验收问题 | 结果依据 | 耗时 |
| --- | --- | --- |
| 单局总量 | 28,152，与独立 SQL 的不同单局计数一致 | 4.547秒 |
| 出场最多的五位选手 | 名称、数量、顺序均与独立 SQL 一致 | 4.516秒 |
| Faker/Chovy 同位置五指标比较 | 指标值和每项有效样本与独立 SQL 一致 | 3.469秒 |
| T1 对 GEN 直接交手 | 双方和对手条件正确，结果与独立 SQL 一致 | 2.765秒 |
| 飞科使用阿狸的表现 | 解析为 Faker/九尾妖狐，真实库没有符合的已知英雄样本，正确返回空结果 | 2.079秒 |
| 2024 已确认赛程范围 | 不使用来源更新时间冒充2024赛事，结果与独立 SQL 一致 | 1.562秒 |
| 只数来源已核验单局 | 89局，与独立 SQL 一致 | 5.093秒 |
| 谁最强 | 返回指标和位置澄清，无模型请求 | 本地处理 |
| 当前版本 ban 率 | 说明补丁和禁用数据未收录，无模型请求 | 本地处理 |

9类问题最终均通过。首次实调发现模型会给总量查询返回 `order_by: null`；修正为业务默认排序后重新验证两个受影响用例，不允许空字符串或未知字段绕过校验。空样本结果核对实际范围，不以模型解释是否流畅作为通过依据。

真实网站另做一轮完整问答：比较 Faker/Chovy 返回两行，约5.000秒；携带上一有效计划追问“只看Faker，其他条件和指标保持不变”返回一行，约3.859秒，指标和位置保持一致。两次请求各使用两次模型调用，没有修复或额外请求。
