# 界面与统计取舍

## 赛事入口优先

这是一个查询真实赛事数据的工具。用户进入首页后，首先需要知道收录范围、最近比赛和查询入口；比赛列表需要直接回答谁对谁、谁赢、打了多久，以及在哪里查看十名选手。

参考 [腾讯体育](https://sports.qq.com/) 的赛事分组与紧凑导航，以及字节 [Arco Table](https://arco.design/vue/component/table) 的表格密度，采用浅灰背景、白色内容区、蓝色操作入口与清晰的中文导航。腾讯体育和 Arco 页面均经过实际浏览器观察；[TDesign 浅色主题](https://github.com/Tencent/tdesign-common/blob/develop/style/web/theme/_light.less) 只参考公开主题定义，未把未成功加载的页面当作视觉证据。

具体选择：

- 首页最近比赛与 AI 查询并列，下面提供选手、战队、英雄和比较分析入口，避免把操作埋在装饰性大图中。
- 比赛表格在桌面直接显示双方、胜负、时长和核验状态；手机改用逐场卡片，保留详情按钮。
- 图表按需加载；胜率、KDA、场次等指标沿用真实样本，不编造未发布比分或把缺失值显示成零。
- 查询错误、空结果和加载分别表达。AI 是可选入口，选手与比赛查询仍可独立使用。
- 数据范围与来源说明留在页面中；核验数不等于历史覆盖率，旧记录的来源更新时间不等于比赛日期。

这次取舍增加了首屏信息密度，减少了装饰空间。首页只展示少量最近单局，完整查找通过列表筛选和分页完成；不把同一 BO 系列的多局结果混写成系列比分。

## 验证范围

2026-10-03 实际浏览器检查 1440px 桌面和 390px 手机：首页、比赛分页与十人详情、Faker 详情、T1 战队详情、中文英雄、同位置雷达和战队比较。页面没有整体横向溢出，浏览器错误与控制台错误为空。后续AI结果呈现补充真实响应、有效样本、追问和折叠SQL检查，具体见 `AI-EVALUATION.md`；前端回归与生产构建通过。

## 数据问答的业务层

旧问答只把数据库字段说明交给模型生成 SQL。它缺少对“场”的定义、日期来源、指标分母、选手转会和相同位置的约束；即使 SQL 能执行，也可能回答另一个业务问题。

[腾讯 ChatBI](https://cloud.tencent.com/document/product/590/107689) 把多轮、澄清、查询与图表纳入同一交互，并提供[业务术语与计算口径知识](https://cloud.tencent.com/document/product/590/114591)。[字节 DataWind](https://docs.volcengine.com/docs/Loading-1/visualizedquery?lang=zh) 的可视化查询支持字段表达式和修复。[Wren AI](https://docs.getwren.ai/oss/guide/modeling/overview) 把元数据、计算字段和关系放入语义模型。这里参考它们对业务口径与查询交互的处理，用轻量模块实现，不引入额外向量数据库或庞大的 BI 平台。

分析流程选择“理解问题 → 受控 JSON 计划 → 实际实体解析 → 可信查询编译 → 只读执行 → 样本与来源证据 → 解释”。模型选择可审核的维度、指标和筛选，代码维护关联、公式、日期来源与数量限制。无效计划最多修复一次，外部服务失败不自动重试付费请求。无法确认名字时给出候选，数据缺项时说明无法计算。

行业参照 [Games of Legends 选手统计](https://gol.gg/players/list/season-ALL/split-ALL/tournament-Road%20Of%20Legends%202026%20Summer%20Split/)：赛事与位置筛选、场次、胜率、KDA、分均指标共同构成比较范围。“谁最强”需要明确指标与位置，不输出凭空合成的实力总分。它提供的补丁、对线差值等角度，目前本项目没有来源字段，不能照抄指标名称后捏造数据。

具体口径：

- 区分一局比赛、选手/战队单局出场和 BO 系列；统计比赛数使用不同单局编号，系列编号未知时明确排除。
- 胜率只以胜负已知的出场为分母；均值只使用该指标非空样本，并报告样本量。
- 平均单局 KDA 与汇总击杀助攻/死亡分别提供，名称和公式分开表达。
- 选手所属战队取每次出场时的战队，避免把转会前表现全部算入最新战队。
- 时间筛选和月趋势只使用真实赛程。仍未回填的来源更新时间保留档案，但不进入年份判断。
- 默认查询可包含未核验旧记录，并展示质量证据；用户可显式限定已核验。只剩几十局核验数据时，悄悄限定核验会使绝大多数问题变成空结果。
- 同位置榜单保留最低场次；样本不足时返回真实空结果，不擅自降低门槛。
- 结果先显示范围、质量与结构化数据，再提供可展开的统计口径和AI解读；避免手机用户先读两遍长篇规则才能看到指标。没有数据、需要澄清或不支持的问题直接显示解释。

这些选择牺牲了任意 SQL 的表达范围，换取可检验的业务结果。新增分析角度应先加入有公式与关联定义的目录，再进入模型可选范围。
